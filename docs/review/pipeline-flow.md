## フェーズ分類キーワード

| フェーズ | キーワード（抜粋） |
|---------|----------------|
| `command_select` | たたかう, Fight, 祟る, わざ |
| `switch_select` | どのポケモン, Which Pokemon |
| `animation` | こうかは, 効果は, バツグン, いまひとつ |
| `faint` | HP正規表現 `0/\d+` |
| `battle_end` | 勝ち, 負け, 引き分け, Win, Lose |
| `selection_screen` | 参加バトルチーム, battle team |

## BattleStateTracker 管理情報

```
BattleStateTracker
├── _player: List[FieldPokemon]  # 最大4スロット
│   └── FieldPokemon
│       ├── name          # ポケモン名（OCR+PokeClassifier）
│       ├── hp            # "176/176" 形式（最新値）
│       ├── status        # まひ/やけど/どく/ひんし（YOLO）
│       ├── moves_used    # 使用技リスト（最大4件）
│       ├── on_field      # 現在場にいるか
│       ├── fainted       # 気絶済み
│       ├── confidence    # 検出回数（信頼度）
│       └── last_seen_turn# 最後に検出されたターン
└── _opponent: List[FieldPokemon]  # 同上
```

## 既知の課題・精度問題

### フェーズ検知

| 課題 | 詳細 |
|------|------|
| `battle_start` タイミング | 「ゆけつ」アニメ中（通信中テキスト）に発火するため、初回ボール数が0になる |
| `move_used` 多重発火 | コマンド選択→unknown→コマンド選択でデバウンス10秒が機能しないケースあり |
| `faint` 検知遅延 | HP=0テキストがOCRに乗るまでラグがある |

### ポケモン名検出

| 課題 | 詳細 |
|------|------|
| OCR誤読 | 「トロクツキ」「バドレツクス」など1文字ずれが発生 |
| 登録遅延 | 試合開始直後（T1〜T4）はOCRが拾えず「情報収集中」になる |
| 同名ポケモン | 両チームに同じポケモンがいる場合、相手優先で登録されて自分側に追加できない |

### HP管理

| 課題 | 詳細 |
|------|------|
| y座標分類ミス | HP値の画面上の位置が変動すると自分/相手の分類が逆になる |
| HP紐付けミス | 場の2匹のHPをインデックス順で紐付けるため、交代直後に入れ替わるケースあり |

### ボール検出

| 課題 | 詳細 |
|------|------|
| `battle_start` 時は0 | 「ゆけつ」アニメ中のため検出できない（2回目の command_select で取得） |
| conf スコアが低い | train7 の出力が全体的に低め（0.05前後）→ 閾値 0.05 で対応中 |

## Bedrock プロンプトに渡している情報

```
【現在の状況】
- イベント種別: move_used / faint / switch / battle_start / battle_end
- ボール残数: 自分N匹 / 相手N匹
- 状態異常: まひ etc.

【戦況（BattleStateTracker.to_context()）】
- 自分の場: ポケモン名(状態) HP:XX/XX ★ピンチ 技=[技1, 技2]
- 自分の控え: ポケモン名 HP:XX/XX
- 相手の場: 同上
- 相手の控え: 同上

【ポケモン図鑑情報（PokeDB RAG）】
- タイプ・特性・代表技6つ（確定ポケモン名のみ）

【OCRテキスト】
- 画面から取得した生テキスト（ノイズ含む）

【実況履歴】
- 直近3件の実況文
```

## 改善候補

### 優先度: 高
1. **ポケモン名登録の安定化** — T1〜T4での遅延解消、OCR誤読の吸収強化
2. **HP紐付け精度向上** — y座標分類の安定化、交代後の再マッピング

### 優先度: 中
3. **`battle_start` 初回ボール数** — ゆけつアニメ終了後に確定取得する仕組み
4. **`move_used` 過剰発火抑制** — 短時間内の連続発火を防ぐ条件追加

### 優先度: 低
5. **音声出力二重化** — sounddevice で複数デバイス同時出力
6. **同名ポケモン問題** — 両チームに同じポケモンがいる場合の登録ロジック改善
