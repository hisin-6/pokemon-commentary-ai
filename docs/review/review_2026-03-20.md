## 課題・改善余地

### 1. 超長関数（実装品質・中）

**対象**: `src/pipeline.py` `_extract_structured_info()`（約 117 行）

HP 抽出・ポケモン名候補抽出・技ログ更新が 1 関数に混在しており、バグ追跡・テストが困難。
処理単位でサブ関数に分割することを推奨。

```
_extract_structured_info()
  ├── _extract_hp_values()         # HP 抽出・y座標分類
  ├── _extract_pokemon_candidates() # ポケモン名候補抽出
  └── _extract_move_log()           # 技ログ更新
```

---

### 2. 正規表現の散在（実装品質・低）

**対象**: `src/pipeline.py` 複数箇所

類似する HP 関連の正規表現が複数箇所に定義されている。

```python
hp_pattern   = re.compile(r'\b(\d{1,3})/(\d{1,3})\b')   # 168行付近
_HP_ZERO_RE  = re.compile(r'\b0/([5-9]\d|\d{3})\b')      # 374行付近
_HP_RE       = re.compile(r'(\d{1,3})/(\d{1,3})')         # 485行付近
```

共通の定数モジュール（例: `src/constants.py`）にまとめることで重複を排除できる。

### 5. PokeDB の代表技リスト選出基準（設計・低）

**対象**: `scripts/build_pokedb.py` / `src/pokedb/classifier.py`

現在の代表技は `power 降順` でソートして上位 12 件を返しているため、以下のような採用率の高い補助技・サポート技が出力されない可能性がある。

- ステルスロック（威力なし）
- おいかぜ（威力なし）
- でんじは / どくどく（威力なし）
- その他サポート・状態異常技

実況においてサポート技の情報は重要度が高いため、将来的には Smogon 等の採用率データとの統合を検討する余地がある（Sprint 9 以降）。
