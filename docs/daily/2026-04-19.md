## 完了タスク

### 1. HP OCR 正規化修正（`src/pipeline.py` / `scripts/test_ocr_areas.py`）

**問題**: Champions の hp_plr が `7967135` → `135/135` に直らなかった

**修正内容**:
- `_HP_SLASH_RE` を `[1]` → `[17]` に変更（スラッシュが `7` に誤読されるケースを追加）
- `cur <= mx` チェック追加（分子 > 分母になる誤補正を排除。例: `768/155` はスルー）
- `{→8` 置換を追加（`{0%` → `80%` 等 hp_opp1 でよく発生）
- 両ファイルに同一修正を適用

### 2. `preprocess_hp` 廃止（`src/pipeline.py` / `src/capture/screen_capture.py`）

**問題**: `preprocess_hp=True` でROIクロップ個別OCRをしていたが、Champions の hp_plr が逆に悪化

**原因**: 小さいROI単体でOCRすると空間的文脈が失われ精度低下。フルフレームOCRの方が正確

**修正内容**:
- `pipeline.py` の `run_ocr(reader, frame, preprocess_hp=True)` → `preprocess_hp` 削除
- `screen_capture.py` の HP マスク処理を hp_opp のみに限定（hp_plr はフルフレームに任せる）
  - `_HP_ROIS_1920` → `_HP_OPP_ROIS_1920`（hp_plr ROI を除外）

### 3. hp_plr y座標分類バグ修正（`src/pipeline.py`）

**問題**: Champions の hp_plr が y=1000〜1050 にあるが、パイプラインが取りこぼしていた

**原因**: `elif cy < _COMMAND_Y_MIN (700)` の条件が hp_plr（y=1000〜1050）を弾いていた

**修正**: `elif cy < _COMMAND_Y_MIN:` → `else:` に変更

### 4. デバッグスクリプト修正（`scripts/debug_hp_bbox.py`）
