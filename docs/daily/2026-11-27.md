### 4. RVC: 音色が似ない原因の切り分け

**学習データと学習の確認 → はっきりした問題は無し**

| 項目 | 結果 |
|---|---|
| 量 | 28ファイル・合計約43分（RVC の目安10〜50分の上限寄り） |
| 音質 | 48kHz（中身はモノラル）、高い帯域まで入っていて雑音なし。無音部分は完全なデジタル無音で、録音アプリのノイズ抑制が効いている |
| 音量 | 録音日によって最大約10dBの差。前処理で正規化されるので影響は小さい |
| 学習 | 523スライスに分割されて正常に学習。F0 抽出は rmvpe |

**テスト2: 学習データの録音をモデルに通し直す（`renders/rvc_test2/`）**
- 学習データから12秒ずつ3本切り出し（7/23・8/8・8/15の録音）、e150・e250 で変換した
- 結果: **元の音声とほぼ同じ**。モデルが声を覚えていないという最悪のケースは消えた。ただし学習データそのものなので、甘めの結果になる点に注意

**今の仮説: 変換元が VOICEVOX（合成音声）であることが原因**
- RVC は元の音声から「何をしゃべっているか」の特徴を取り出して、学習した声で作り直す。この特徴には元の話者の声のクセも少し混ざる。人の声どうしなら自然になじむが、合成音声は響き方が独特なので、変換後にも残りやすいと考えている
