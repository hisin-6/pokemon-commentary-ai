#### 問題発生・原因分析・ロールバック
- **症状**: pokemon_g2 使用で battle_start が全く発火しない（総ターン数: 0）
- **原因**: Prediction層が scratch から 444件のみで学習されてしまった
  - pretrained japanese_g2 は 2214文字 → Prediction.weight: [2215, 256]
  - CHARACTERS は 2213文字 → shape mismatch → 形状一致フィルタで Prediction層がスキップ
  - Prediction層をランダム初期化 → 444件で過学習 → メッセージROI以外の認識能力がゼロに
  - `たたかう`/`どうする`（コマンド選択UI）が認識できず `command_select` 未検出
- **対処**: `init_reader` を japanese_g2（["ja", "en"]）に戻す ✅
