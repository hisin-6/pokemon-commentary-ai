# キャラクターデザイン依頼内容

## キャラクター名
**花圓くれぴ**（読み: はなまるくれぴ／ローマ字: Kurepi）

- ひらがな併記が必須の名前です（「圓」が読みにくいため）
- ハッシュタグは `#はなまるくれぴ`

## 見た目・年齢感
- かわいい女性キャラクター
- 年齢層イメージ: 見た目は数年下の妹、もしくは娘くらいの親しみやすさ（外見の印象のみ）(14~15歳くらい)
- 対戦プレイヤーは男性が多い層を想定しているため、親しみやすい・かわいがりたくなる見た目を狙っています
- 身長は低め（140㎝代前半）

## 性格・キャラ性
- 元気
- 甘えん坊
- ポケモン知識は豊富（実況キャラとして中身はガチ）
- 見た目の親しみやすさと、中身のガチ感のギャップが持ち味です

## モチーフ・デザインの方向性
- 普通の人間（猫耳などの獣耳要素はなし）
- 実況キャラ／ポケモントレーナー風の要素は取り入れません。ポケモン要素は実況内容の方で出るため、見た目は魔法少女／アイドル系のキャラ性を優先したいです

### 髪※（こっちのほうがいい！とか挑戦したい！があれば提案していただきたく思っています）
- 色: 限りなく薄いピンク（モチーフであるモモイロタンポポの色）
- 形: ボブ（あご〜肩）、丸みのあるシルエット　
- 前髪: シースルーバングか、丸みのあるぱっつん寄り（幼さ・元気さを強調）。分け目ありで片方だけ軽く跳ねる遊びがあると「甘えん坊」のゆるさが出しやすいと思っています
- ⚠️薄ピンク髪は小さく表示すると白飛びしやすいため、輪郭・瞳・衣装にコントラストを持たせていただけると助かります

### 目・表情
- ぱっちり元気目
- 瞳の色: やや彩度高めの赤紫〜マゼンタ系を希望方向としつつ、他の配色のご提案があればそちらを優先していただいて構いません（ハイライトは白めで大きめに取り、元気さを強調したいです）

### 肌
- 真っ白（アルビノ寄り）は避け、標準〜やや健康的な色白（ほんのり血色感のあるオークル寄り）を希望します

### アクセサリー（ほぼお任せです）
- 主張しすぎない範囲で1〜2点程度
- 例: 星型／花型の小さめヘアクリップ（小花モチーフも候補）

### レッグウェア・靴
- ニーソックス＋スニーカータイプを希望します（ルーズソックスや革靴・ローファーは避けたいです）

## 衣装※（こちらも、こっちのほうがいい！とか挑戦したい！があれば提案していただきたく思っています）
- 希望方向: 女児アニメの魔法少女系、または女児アニメのアイドル衣装（かわいい系）
- 具体イメージ: セーラー服を着崩し、アクセサリーを効かせたコーデ（アイドル系寄りの解釈、ワッチャプリマジ！「ハッピーセーラー」のようなイメージ）
- リボンタイ: 誇張した大き目のシルエットを希望。リボンタイに小さな花モチーフのチャームを付けたいです
- 配色は個別指定せず、下記カラーパレットの範囲内でお任せします
- 上記より良いと考えている衣装があればそちらの提案是非聞きたいです。

### 3D化コスト等の都合で簡略化が必要な場合の優先順位（削るなら上から）
1. 大型アクセサリー・立体的な帽子／リボン → 平面的な意匠に変更、または削除
2. 重ね着・レイヤー多めのスカート → 単層スカートに統一
3. フリル量 → 裾など一部のみに絞る
4. 揺れ物パーツ数（リボン・アクセ等） → 1〜2箇所に絞る
5. 靴・手袋等の小物ディテール → シンプルな形状に

## カラーパレット
- ピンク×淡紫（元気アイドル系）
- 淡紫は瞳・衣装・リボン等の差し色候補です
- **緑系統は使用不可**でお願いします（配信でのグリーンバック合成でクロマキー抜けが起きるため。差し色にも使わないでください）

## 表示サイズについての考慮点
配信・動画では小さめのワイプ（上半身のみのクロップ）で表示されることが多い予定です。（全身も表示する可能性はあります）
- 小さく表示しても映える・視認性の高いデザインにしていただけると助かります
- アクセサリーや装飾など情報量の多い部分は上半身に集めていただけますでしょうか（腰から下はほとんど映りません）
