## 方式C: 立ち絵口パク（ゆっくり実況方式）

### 仕組み

静止画の立ち絵2〜3枚を、パス2が**発話区間だけ自動で口パク切替**して合成する。
発話区間はschedule.json（各実況のstart〜start+duration）から機械的に分かる。

```
素材ディレクトリ（--avatar <dir>）:
  base.png   … 口閉じ（常時表示・透過PNG）
  open.png   … 口開き（発話中に交互表示・透過PNG）
  blink.png  … まばたき（任意・あれば数秒おきに一瞬表示）
```

### 合成方法（ffmpegフィルタ・パス2に追加）

- `base.png` を右下に常時 overlay
- `open.png` を「発話区間 ∧ 口パク周期」の enable 式で overlay:
  `enable='(between(t,s1,e1)+between(t,s2,e2)+…)*lt(mod(t,0.25),0.125)'`
  （0.25秒周期で口を開閉＝約4Hzのパクパク。区間列はschedule.jsonから自動生成）
- `blink.png`（任意）: `enable='lt(mod(t,4.7),0.12)'`（約4.7秒ごとに一瞬）
- 実況の話者は1人（speaker=1）なので、フィラー/イベントの区別なく全発話区間で口パク

### 特徴

| 項目 | 評価 |
|------|------|
| 動画1本あたりの手間 | **ゼロ**（完全自動・量産ライン維持） |
| 実装工数 | 小（パス2のffmpeg合成＋enable式生成＋テストで半日弱） |
| 口パク精度 | フレーズ単位（音素レベルではない）。ゆっくり実況ではこれが標準で違和感なし |
| 見た目 | 静止画＋口パク＋まばたき。表情差分を増やせば豊かにできる（イベント種別で差し替え等の発展余地） |
| 素材の用意 | 立ち絵2〜3枚（透過PNG・推奨 元サイズ600×800程度） |
| リスク | ほぼなし（全部ffmpegの既存機能） |

### 発展オプション（後日）

- イベント種別で表情差し替え（faint=驚き顔・battle_end=笑顔等。manifestのevent_typeから機械的に切替可能）
- 音声波形連動の口開度（要追加解析・優先度低）

## 方式A: VMC録画ワイプ（当初案）

### 仕組み

パス2が生成する実況トラックWAV（`commentary_track.wav`＝動画と同尺）を再生しながら、
バーチャルモーションキャプチャー(VMC)の3Dモデルにリップシンクさせ、その画面を
グリーンバックで録画。パス2がクロマキー合成する。

### 手順（動画1本ごと・すべてリアルタイム）

1. パス2を一度実行して `renders/<名前>/commentary_track.wav` を得る
2. Windows側の準備:
   - VMC＋3Dモデル起動・背景をグリーン単色に
   - **音声ルーティング**: WAV再生をVMCのリップシンク入力に届ける仮想オーディオ
     ケーブル（VB-Cable等）の導入・設定が必要
3. WAVを頭から再生しつつOBSでVMCウィンドウを録画 → `avatar.mp4`（動画と同尺）
4. パス2を `--avatar-video avatar.mp4` で再実行:
   `chromakey → scale → overlay`（右下・方式Cと同じ位置）

### 特徴

| 項目 | 評価 |
|------|------|
| 動画1本あたりの手間 | **動画実時間＋段取り**（6分動画なら10分前後・毎回リアルタイム拘束） |
| 実装工数 | パス2側は小（chromakey＋overlay）。**本体は運用構築**（音声ルーティング・録画開始とWAV再生の頭合わせ） |
| 同期リスク | 録画とWAVの頭合わせが手動だと±数百msズレる。対策=再生と録画を同時に叩くスクリプト or 冒頭にクラップ音＋フラッシュを入れて後から合わせる |
| 見た目 | 3Dモデルが常時ゆらぎ・リップシンクも滑らか。最もリッチ |
| 追加ソフト | VB-Cable等の仮想オーディオデバイス（無料・要インストール） |
| リスク | VMCのリップシンク入力仕様・クロマキーの抜け調整・毎回の人的ミス（頭合わせ忘れ等） |

## 比較まとめと推奨

| | C: 立ち絵口パク | A: VMC録画 |
|---|---|---|
| 量産適性 | ◎ 全自動 | ✗ 毎回リアルタイム |
| 実装リスク | ほぼなし | 運用構築が本体 |
| 見た目 | ゆっくり実況風 | VTuber風・リッチ |
| 素材 | 立ち絵2〜3枚 | 3Dモデル＋録画環境 |

**推奨: まずCで量産ラインを完成させ、こだわり動画のみ後からAを追加する2段構え。**
どちらも同じ右下枠・同じパス2フックを使うため、`--avatar <dir>`（C）と
`--avatar-video <mp4>`（A）は共存でき、動画ごとに選べる。
